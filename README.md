# Task Order - Sistema de Lista de Tarefas

## Sobre o Projeto

O Task Order é uma aplicação web desenvolvida como trabalho bimestral da disciplina de **Programação de Aplicação Internet**.

O objetivo do projeto é permitir o gerenciamento de tarefas de forma simples e intuitiva, utilizando apenas tecnologias nativas da web:

- HTML5
- CSS3
- JavaScript

O sistema foi construído aplicando conceitos fundamentais de programação estudados em sala de aula, incluindo Programação Orientada a Objetos, manipulação do DOM, tratamento de erros e estruturas de controle.

___


## Funcionalidades

### Cadastro de tarefas

O usuário pode criar novas tarefas informando:

- Título
- Descrição
- Prioridade:
  - Baixa
  - Média
  - Alta
  - Extremamente Alta

### Gerenciamento de tarefas

- Visualizar tarefas cadastradas
- Marcar tarefas como concluídas
- Reabrir tarefas concluídas
- Remover tarefas
- Limpar todas as tarefas

### Filtros

Filtragem por:

- Status
  - Todas
  - Pendentes
  - Concluídas

- Prioridade
  - Baixa
  - Média
  - Alta
  - Extremamente Alta

## Informações exibidas

Cada tarefa apresenta:

- Título
- Descrição
- Prioridade
- Data de criação
- Status atual

## Como Executar

1. Clone o repositório:

Não é necessário instalar dependências ou executar servidores externos.
